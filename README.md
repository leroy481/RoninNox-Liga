# RONIN NOX — STREET RACING DIVISION

Fertiger visueller und interaktiver Browser-Prototyp auf Basis des RONIN-NOX-Konzepts.

## Direkt öffnen
`public/index.html` doppelklicken oder `START-WINDOWS.bat` ausführen.

## Demo
KAZE / ronin123
AKUMA / ronin123

## Enthalten
- responsive Street-Racing Landingpage
- Next Race mit Countdown und Renninformationen
- Current Season / All-Time Leaderboard
- Rennarchiv
- Regelwerk und Sanktionskatalog
- Login / Fahrerprofil
- interaktive Teilnahme- und Detail-Dialoge
- mobile Darstellung

Die im Ordner enthaltene Node/SQLite-Grundlage ist separat vorhanden und kann als technische Basis für den echten Serverbetrieb genutzt werden.
